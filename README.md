# Phytomni

A central index of code, training datasets, and evaluation benchmarks for Phytomni, an agentic AI system for plant research.

## Code

| Resource | Description |
| --- | --- |
| [Phytomni-Bot](https://github.com/Phytomni/Phytomni-Bot) | Core agentic system, including system architecture and inference pipelines. |
| [Phytomni-Web](https://github.com/Phytomni/Phytomni-Web) | Frontend and backend for the interactive web interface. |
| [Phytomni-Manuscript](https://github.com/Phytomni/Phytomni-Manuscript) | Scripts and notebooks for reproducing manuscript figures, tables, and statistical analyses. |

Archived Phytomni-Bot source code: [Zenodo record](https://zenodo.org/records/17349041).

## Training datasets

| Dataset | Description |
| --- | --- |
| [Phytomni-Pretrain](https://huggingface.co/datasets/Phytomni/Phytomni-Pretrain) | Plant-science corpus for continual pre-training. |
| [Phytomni-SFT](https://huggingface.co/datasets/Phytomni/Phytomni-SFT) | Instruction-tuning dataset for supervised fine-tuning across six plant-science task categories. |

## PhytoBench

Browse the [PhytoBench collection on Hugging Face](https://huggingface.co/collections/Phytomni/phytobench-689b39c42e894e57a3914b1e) or open an individual evaluation subset below.

| Benchmark | Evaluation focus |
| --- | --- |
| [PhytoBench-Knowledge](https://huggingface.co/datasets/Phytomni/PhytoBench-Knowledge) | Factual plant-biology knowledge. |
| [PhytoBench-Data](https://huggingface.co/datasets/Phytomni/PhytoBench-Data) | Interpretation of and reasoning over structured experimental data. |
| [PhytoBench-Analysis](https://huggingface.co/datasets/Phytomni/PhytoBench-Analysis) | Multi-step analytical reasoning in plant science. |
| [PhytoBench-Review](https://huggingface.co/datasets/Phytomni/PhytoBench-Review) | Critical synthesis of published findings. |
| [PhytoBench-Paper](https://huggingface.co/datasets/Phytomni/PhytoBench-Paper) | Comprehension and information extraction from full-length research articles. |
| [PhytoBench-Gene](https://huggingface.co/datasets/Phytomni/PhytoBench-Gene) | Gene annotation, function prediction, and nomenclature. |

See the linked repositories and dataset pages for usage instructions, documentation, and license terms.
